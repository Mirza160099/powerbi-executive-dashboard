# Interview Case Study

## Situation
Leadership needs a concise view of commercial performance but existing reports contain too many disconnected metrics.

## Task
Design an executive Power BI reporting model that shows performance against target and enables controlled drilldown into the drivers of variance.

## Action
- Created a synthetic sales dataset.
- Transformed it into a star schema with reusable dimensions.
- Defined Power Query cleaning/type-validation steps.
- Built a DAX measure library covering revenue, margin, target, variance, YoY, YTD and rolling performance.
- Designed an executive page, commercial performance page, variance page and drillthrough view.
- Documented KPI hierarchy and executive storytelling.

## Result
Produced a portfolio-ready BI solution demonstrating semantic modelling, Power Query, DAX, KPI architecture and decision-focused reporting.

## Interview Talking Points
1. Why star schema matters.
2. Measures vs calculated columns.
3. Filter context.
4. CALCULATE.
5. Time intelligence.
6. Actual vs target variance.
7. Drillthrough vs drilldown.
8. Power Query vs DAX transformations.
9. How you validate dashboard numbers.
10. How you avoid clutter in executive reporting.
