# Variance Analysis

This project uses **business variance** rather than statistical variance.

## Core Business Variance

```text
Variance = Actual Revenue - Target Revenue
Variance % = (Actual Revenue - Target Revenue) / Target Revenue
```

Positive variance means performance is above target.

Negative variance means performance is below target.

## Recommended Analysis Path

1. Confirm total variance.
2. Split by region.
3. Split by product.
4. Split by channel.
5. Review margin and discount changes.
6. Drill through into underlying detail.

## Why Variance Matters

A revenue figure without comparison lacks context. Variance adds a decision benchmark:
- plan
- budget
- forecast
- prior year
- prior period
